# Agent instructions

This repo is design notes, not code. Before creating, moving, or editing any doc:

1. Read the rules in [README.md](README.md) and follow them.
2. New docs start from [_templates/doc.md](_templates/doc.md) (decisions from [_templates/decision.md](_templates/decision.md)), status line first.
3. Pick the folder by the question the doc answers (rule 2). Exploration file names are dated: `YYYY-MM-DD-<topic>.md`.
4. Add or update the doc's row in its area README in the same change. Moving a doc to `archive/` adds a row there naming where the current truth is.
5. Never write logs, generated output, or screenshots outside `qa/<date>-<topic>/`.
